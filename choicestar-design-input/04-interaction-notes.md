# 04 · 全局交互规则

## 导航
- 顶部固定导航栏，高度 64px，背景白色 95% 透明度 + 底部细线
- 当前页面菜单项高亮：文字 `#4C6EF5` + 下划线指示器
- 二级页面 / 标签页切换：无刷新，内容区域淡入淡出

## 通用状态
- **Hover**：卡片轻微上移 -2px，阴影加深
- **Loading**：骨架屏 + 旋转 loading 图标
- **空态**：插画 + 引导文案 + 操作按钮
- **错误态**：红色提示条 + 重试按钮

## 微动效
- 页面切换：fade 250ms
- 卡片出现：stagger fade-up，间隔 60ms
- 数字滚动：从 0 滚动到目标值，持续 1.2s
- 收藏按钮：点击后心形缩放 + 颜色变化
- 按钮按下：scale 0.98

## AI 助手
- 右下角悬浮按钮，圆形，主色渐变
- 点击展开聊天窗口，左侧头像，右侧气泡
- 提供 5 个快捷问题

## 弹窗
- 居中显示，背景黑色 30% 透明度遮罩
- 弹窗圆角 16px，最大宽度 520px
- 关闭：点击遮罩、ESC、右上角 X

## 响应式断点
- 1440px+：完整三栏/双栏
- 1280px：紧凑双栏
- 768px：单栏 + 抽屉导航
- 375px：移动端单列，底部 tab 导航
