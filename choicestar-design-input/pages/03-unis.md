# 院校库

## 页面定位
查询和浏览全国院校详情。

## 页面结构

### 1. 页面标题区
- 标题：院校库
- 副标题：3000+ 院校全维度数据，帮你找到最适合的目标
- 搜索框：搜索院校名称 / 地区 / 层次

### 2. 筛选栏
- 院校层次：全部 / 985 / 211 / 双一流 / 省重点 / 普通本科
- 所在地区：省份多选
- 院校类型：综合 / 理工 / 师范 / 财经 / 医药 / 艺术等
- 办学性质：公办 / 民办 / 中外合作
- 更多筛选：学费范围、博士点数量等

### 3. 院校列表
- 视图切换：卡片视图 / 列表视图
- 排序：综合排序 / 录取概率 / 热度 / 分数线
- 卡片内容：
  - 院校 Logo 占位
  - 院校名称
  - 层次标签组
  - 所在城市
  - 综合评分（五星）
  - 2025 分数线 / 位次
  - 热门专业 3 个
  - 收藏按钮

### 4. 分页
- 同智能填报

### 5. 院校详情入口
- 点击卡片进入详情页（可在当前页用右侧抽屉或弹窗展示）
- 详情包含：院校简介、招生计划、历年分数线、专业列表、就业报告、校园风光

## 视觉重点
- 筛选标签用胶囊样式
- 列表视图信息更紧凑
- 层次标签用不同颜色区分
