# 专业库

## 页面定位
查询和了解本科专业信息。

## 页面结构

### 1. 页面标题区
- 标题：专业库
- 副标题：1500+ 专业深度解析，从学科门类到就业去向
- 搜索框：搜索专业名称 / 门类 / 学科

### 2. 专业分类导航
- 横向分类标签：全部 / 工学 / 理学 / 文学 / 经济学 / 管理学 / 医学 / 法学 / 教育学 / 艺术学
- 当前分类高亮

### 3. 专业卡片列表
- 每张卡片：
  - 专业名称
  - 学科门类标签
  - 修业年限（4 年 / 5 年）
  - 授予学位
  - 专业热度（火焰图标 + 数值）
  - 薪资指数（柱状图或星级）
  - 就业方向标签
  - 适合人群（如：逻辑思维强、喜欢编程）

### 4. 专业详情
- 弹窗或抽屉形式
- 包含：专业介绍、核心课程、就业前景、推荐院校、相似专业、学长评价

## 视觉重点
- 分类标签可横向滚动
- 薪资/热度用小型图表展示
- 卡片整齐网格布局
