# 模拟填报

## 页面定位
模拟真实志愿填报表，提前演练并检查风险。

## 页面结构

### 1. 页面标题区
- 标题：模拟填报
- 副标题：真实还原本省志愿表，提前排查风险

### 2. 志愿表操作区
- 志愿表名称：如「北京 2026 物理类 本科批」
- 操作按钮：清空志愿表 / 导入推荐方案 / 智能检查
- 批次切换标签：本科提前批 / 本科批 / 专科批

### 3. 志愿表格
- 表格列：志愿序号、院校、专业 1-6、是否服从调剂、操作
- 每行一个志愿
- 支持拖拽排序（拖拽图标）
- 空行显示「+ 添加院校」按钮

### 4. 右侧辅助面板
- 考生分数卡片
- 已选院校统计：冲 / 稳 / 保 数量
- 风险提示列表

### 5. 智能检查结果
- 弹窗或展开面板
- 检查项：
  - ✓ 梯度合理
  - ✓ 无重复院校
  - ⚠ 专业 2 与专业 3 录取分倒挂
  - ✗ 未勾选服从调剂
- 修复建议按钮

## 视觉重点
- 表格行可拖拽排序
- 风险项用红黄绿标签
- 空态引导添加第一个志愿
