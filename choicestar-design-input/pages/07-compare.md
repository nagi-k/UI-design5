# 对比工具

## 页面定位
帮助用户在多个院校/专业之间做对比决策。

## 页面结构

### 1. 页面标题区
- 标题：对比工具
- 副标题：最多对比 4 个院校或专业，关键指标一目了然
- 切换：院校对比 / 专业对比

### 2. 选择区
- 搜索框添加对比项
- 已选项横向排列，带删除按钮
- 空位显示「+ 添加」占位卡片

### 3. 对比表格
- 左侧：对比维度
  - 基本信息：名称、层次、地区、类型
  - 录取数据：2025 最低分 / 位次 / 录取概率
  - 专业实力：重点学科数、博士点、专业排名
  - 就业数据：就业率、平均薪资、热门去向
  - 校园生活：城市等级、校园面积、宿舍条件
- 右侧：每个对比项对应数据
- 最优项用主色高亮

### 4. 底部操作
- 导出对比表
- 加入志愿表
- 重新选择

## 视觉重点
- 表格固定左侧维度列
- 最优指标用 🏆 或主色背景标注
- 对比项数量限制提示
