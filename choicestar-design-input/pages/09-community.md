# 社区

## 页面定位
考生交流平台，增强粘性和信任。

## 页面结构

### 1. 页面标题区
- 标题：择校星社区
- 副标题：和 128 万考生一起交流志愿填报
- 发布按钮：+ 发布问题

### 2. 内容分类
- 标签：全部 / 经验分享 / 院校问答 / 专业讨论 / 分数线交流 / 求助

### 3. 帖子列表
- 每条帖子：
  - 作者头像 + 昵称
  - 标题
  - 摘要（2 行）
  - 标签
  - 数据：点赞、评论、浏览、时间
- 置顶帖有「置顶」标签

### 4. 右侧边栏
- 热门话题榜
- 精华帖推荐
- 社区规则
- 专家在线卡片

### 5. 帖子详情（弹窗/新页）
- 标题、正文、评论区
- 点赞、收藏、分享、回复

## 视觉重点
- 社区氛围轻松
- 帖子列表信息密度适中
- 侧边栏用卡片分组
