# 如何把本输入包喂给 Trae Design / AI 画布

## 方式一：有界面截图（效果最好）

### 步骤
1. 打开 `prototype/index.html`（建议用 Chrome）
2. 按 `screenshot-guide.md` 截取 10 个核心页面的全屏图
3. 把截图重命名为：`home.png`, `smart.png`, `unis.png`, `majors.png`, `assess.png`, `mock.png`, `compare.png`, `career.png`, `community.png`, `profile.png`
4. 放入 `assets/screenshots/`
5. 在 Trae 中新建 Design / AI 画布，发送如下提示词：

```
请根据我上传的高考志愿填报产品「择校星 ChoiceStar」的界面截图和设计规格，在画布中生成 10 个高保真 Web 界面页面，按信息架构顺序横向排列。风格参考截图：浅灰蓝主色 #4C6EF5、卡片式布局、圆角 16px、阴影柔和、信息密度高。每个页面标题用中文标注，页面之间用流程线连接。生成后我要导出到 Figma 微调。
```

6. 分批上传截图（一次 3-4 张），先上传 `home.png`, `smart.png`, `unis.png`
7. 再上传对应 `pages/01-home.md`, `pages/02-smart.md`, `pages/03-unis.md` 作为补充
8. 重复直到 10 个页面全部生成

## 方式二：没有截图（用文字 + 原型）

如果来不及截图，可以直接把 `pages/*.md` 的内容复制给 AI：

```
请根据以下详细页面规格，为「择校星 ChoiceStar」生成 10 个高保真 Web 界面。我已提供可交互原型 HTML 文件供你参考整体结构。设计要求：主色 #4C6EF5、背景 #F8FAFC、卡片 #FFFFFF、文字 #111827、圆角 16px、桌面端 1440px。请先生成首页，确认风格后再继续生成其余页面。
```

然后把 `prototype/index.html` 作为附件上传。

## 给 AI 的关键提示词模板

### 生成单页
```
请生成「择校星」的【智能填报结果页】，桌面端 1440px 宽度。
- 顶部：固定导航栏，logo + 10 个菜单项 + 搜索 + 通知 + 登录按钮
- 左侧边栏：筛选条件（省份、科类、批次、意向方向、院校层次）
- 右侧主内容：考生分数卡片 + 冲/稳/保 三个标签页 + 院校推荐卡片列表
- 每张卡片包含：院校 Logo 占位、院校名称、录取概率、最低分/位次、专业标签、收藏按钮
- 底部：分页器和 AI 助手悬浮按钮
- 颜色：主色 #4C6EF5，成功 #22C55E，警告 #F59E0B，危险 #EF4444
```

### 统一风格
```
所有页面必须统一使用以下设计系统：
- 背景：#F8FAFC
- 卡片背景：#FFFFFF
- 主色：#4C6EF5
- 强调色：#38BDF8
- 主要文字：#111827
- 次要文字：#6B7280
- 边框：#E5E7EB
- 大标题 24-32px 加粗，正文 14px，辅助 12px
- 卡片圆角 16px，按钮圆角 12px，标签圆角 999px
- 阴影：0 4px 20px rgba(0,0,0,0.06)
```

## 导出到 Figma

1. Trae AI 画布生成完成后，点击右上角「下载」或「导出」
2. 通常可导出为 PNG / SVG / Figma 文件
3. 如果没有直接 Figma 导出，先导出 PNG/SVG，再在 Figma 中「文件 → 导入」
4. 在 Figma 中用 Frame 重新组织页面，添加 Auto Layout，微调间距和颜色
